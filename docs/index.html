DCI CTP Test Suite

Synthetic packaging, composition, presentation, picture, integrity, and security cases for dcpdoctor, plus real generated and ISDCF DCPs. CI creates the fixtures and runs the full suite; the 2GB ISDCF cases skip.

Run it

./scripts/create_synthetic.sh
./scripts/run_tests.sh \
  --dcpdoctor ../dcpdoctor/rust/target/release/dcpdoctor

Large ISDCF samples stay optional and outside Git.
